Adhan playback — mediaPlayback

Prayer reminders are enabled in Settings with Adhan sound selected. An actual alarm invokes the existing PrayerAlarmReceiver and AzanPlaybackService. Audible adhan continues while the app is backgrounded. The user stops it using the notification’s “Hentikan azan” action.

Why foreground execution is used

This is the existing user-enabled prayer reminder. Playback needs to start at the reminder time and continue when the reader is not open. Delaying or stopping it would cut off the audible prayer reminder. The foreground notification identifies the playback and provides a Stop action; the service ends when stopped or finished.

Recording details

For a repeatable recording, an instrumentation-only helper schedules an exact alarm to the existing production PrayerAlarmReceiver. It does not mock the receiver, service, notification, audio, or Stop control, and is not packaged in the production app. The recording shows actual device audio. The in-app volume preview and Quran player are not claimed to use this foreground service.
